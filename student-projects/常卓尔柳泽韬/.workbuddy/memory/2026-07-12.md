## 🐞 严重 BUG：改版导致老玩家存档被清空（已修复）
- 现象：用户刷新/重开页面后，战魂/卡片/花园树/积分/拼图/大树全部归零
- 根因：本次改版在 load() 内调用了 grantPlantQuota()，而 load() 处于 `let state = load()` 初始化期；grantPlantQuota 内部引用模块级 `state`，触发 TDZ(ReferenceError: Cannot access 'state' before initialization)；被 load 的 try/catch 捕获后 `return defaultState()`，对"有存档的老玩家"直接返回空档 → 后续任何 save() 又把空档写回 localStorage，整档丢失
- 修复：grantPlantQuota(s) 改为接收目标 state 参数（load 内传 st，其余调用不传则默认 state）；load/save 增加 _bak 双写备份 + 主存档损坏回退备份；load 的 read 单独 try/catch 防 JSON 解析炸
- 验证：mock canvas 预置"老玩家富存档"(战魂25/拼图12/大树4/树1/卡1/植物1/收藏/武器等级/皮肤/签到) 跑 load，12 项断言全 OK（存档完整保留、额度正确结算）。注意：此前的旧测试因 localStorage 始终为空，未覆盖"有存档"路径，故漏掉该回归
- 教训：在 `let x = fn()` 这种初始化表达式里调用的函数，绝不能引用 x 自身；涉及存档读写的改动，必须补"预置已有存档"的回归测试
- 验证：mock canvas 跑 默认全解锁(10)/集5块→+3、集15块→+9/额度0禁种/种2耗2/树卡不受影响/renderGarden(额度0与3)/战斗胜发放额度(earned=1) 全 OK
